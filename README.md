# 折影猜意

《折影猜意》是一款以中国剪纸为核心交互机制的 Web 竞猜游戏。玩家在折叠后的红纸上剪裁局部形状，系统根据折法自动展开为对称剪纸图案，其他玩家像“你画我猜”一样猜出剪纸者想表达的具体物体或场景。

## 作品亮点

- 将剪纸的“折叠、剪裁、展开”变成实际玩法限制，而不是只做视觉皮肤。
- 支持二折、四折两种房间难度：二折适合清楚轮廓，四折适合窗花感和中心图案。
- 剪纸者通过有限刀口表达题目，猜题者围绕展开后的图案实时猜测。
- MVP 已包含大厅、房间选择、剪纸编辑器、展开预览、Bot 猜题模拟、P2P 联机房间、计分和结果页。

## 技术栈

- React
- TypeScript
- Vite
- Canvas / SVG 风格交互
- lucide-react 图标

## 本地运行

```bash
npm install
npm run dev
```

构建生产版本：

```bash
npm run build
npm run preview
```

## 在线联机

当前多人模式使用 PeerJS 做浏览器 P2P 房间：

1. 房主点击“创建联机房”，复制房间码或邀请链接。
2. 其他玩家打开链接，输入昵称后加入。
3. 房主点击“开始游戏”并剪纸，加入者实时观看并抢答。
4. 猜词、猜中状态、分数和结果页由房主端同步给全房间。

GitHub Pages 可以托管当前静态前端；如果仓库是私有仓库，当前 GitHub 计划可能不允许开启 Pages。
