# 谁是大裁谜 · 软乎乎剪纸派对

> 剪一小块，展开一大张 —— 剪纸版「你画我猜」

《谁是大裁谜》是一款以中国剪纸为核心交互机制的 Web 多人竞猜游戏。玩家不是在画布上直接作画，而是在**折叠后的红纸上剪裁局部形状**；系统根据当前折法自动镜像、旋转并展开纸片，生成完整的对称剪纸图案；其他玩家需要像「你画我猜」一样，猜出剪纸者想表达的具体物体。

核心创新在于：**剪纸不是视觉皮肤，而是玩法约束**。你只能在折叠纸面上用有限刀口表达形意，展开后的对称效果既可能惊艳全场，也可能离谱到让人笑出声 —— 这种天然的反差，正是游戏的乐趣来源。

在线试玩：<https://LeonidasZhak.github.io/who-is-the-cut-master/>

## 作品亮点

- **玩法创新**：把剪纸的「折叠、剪裁、展开」三步骤变成核心交互，而非美术包装。
- **萌系世界观**：软乎乎剪纸团子、吃瓜观战小伙伴，可爱治愈的视觉和文案贯穿始终。
- **物理剪纸机制**：闭合剪口形成镂空掉片、边缘剪口形成缺口、开放剪线表现为细缝 —— 不是简单的画白线，而是模拟真实剪纸逻辑。
- **多人联机房间**：支持房主创建房间、好友输入房间码加入、等待区开始游戏、剪纸轨迹同步、猜词消息同步和结算同步。
- **轮流剪纸与抢答计分**：每局结束后自动结算，下一局会切换剪纸者；猜中越早得分越高，剪纸者也按被猜中的人数获得分数。
- **手机端适配**：大厅、房间等待、剪纸、猜词、结算流程均做了移动端布局，手机浏览器可直接加入。
- **轨迹辅助系统**：移动平均平滑 + RDP 路径简化 + 吸附闭合，按房间难度自动分级，手抖也能剪出干净线条。
- **放大精修模式**：1x / 1.5x / 2x 三档缩放，方便微操。
- **倒计时压迫感**：≤10 秒时计时器逐秒加速 + 心跳脉冲动画，≤5 秒时变红抖动，真实紧迫节奏。
- **单机陪玩兜底**：没有好友加入时，萌系 Bot 会作为本地陪玩参与抢答，保证 Demo 随时可演示。
- **实时预览**：左画布剪裁，右画布实时展开预览，所见即所得。

## 房间与难度

| 房间 | 折法 | 难度 | 效果 |
|------|------|------|------|
| **镜像热身局** | 二折，可在横折 / 竖折之间切换 | 轻松上手 | 一条折线做镜像，适合爱心、猫脸、小鱼、树叶等轮廓题 |
| **窗花进阶局** | 四折 | 略有挑战 | 四向重复花纹，像真正的窗花剪纸 |

## 技术栈

- **React 19** + **TypeScript** — 类型安全的 UI 层
- **Vite 7** — 极速开发与构建
- **SVG 原生渲染** — 折叠纸面几何 + 展开对称计算，无第三方图形库
- **Web Audio API** — 全部音效由代码合成（剪刀、滴答、猜中/猜错、展开），零外部音频文件
- **Lucide React** — 图标系统
- **CSS 原生动画** — 气泡浮游、计时器脉冲、纸屑飘落

**剪纸编辑器技术细节**：
- 折叠区域 clamp（二折半平面、四折 1/4 扇形）
- 路径闭合检测（首尾 3 点平均距离算法）
- Ramer–Douglas–Peucker (RDP) 路径简化
- 移动平均平滑（窗口 3/5/7 按难度分级）
- 边缘吸附 + 闭合吸附
- SVG viewBox 动态缩放实现放大镜

**音效系统技术细节**：
- 全部使用 Web Audio API 的 OscillatorNode + GainNode + BiquadFilter 实时合成
- 剪刀音效：带通滤波白噪声（模拟纸张切割声）
- 滴答声：方波 + 频率分档（>25s 低频 / 10-25s 中频 / ≤10s 高频）
- 猜中音效：三角波四音阶上扬和弦
- 展开音效：正弦滑音（200Hz→900Hz）+ 三角波低频铺垫
