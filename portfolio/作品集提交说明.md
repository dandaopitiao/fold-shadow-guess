## 作品简介（可直接复制使用）

### 完整版

《谁是大裁谜》是一款以中国剪纸为核心交互机制的 Web 多人竞猜游戏。与传统「你画我猜」不同，玩家不是在画布上直接画图，而是在**折叠后的红纸上用剪刀剪裁局部形状**。系统会根据当前折法自动镜像、旋转并展开纸片，生成完整的对称剪纸图案。5 位萌系 Bot 猜题者根据最终展开效果，像「你画我猜」一样竞猜玩家剪的是什么物体。

游戏的核心创新在于：**剪纸不是视觉包装，而是玩法约束**。你只能在折叠纸面的狭窄空间里用有限刀口表达形意。展开后的对称图案可能惊艳全场，也可能离谱到让所有人笑出声 —— 这种「创作受限 → 展开惊喜 → 集体误读」的三段式体验，构成了游戏最独特的趣味引擎。

**技术亮点**：
- 所有剪纸物理（折叠 clamp、闭合掉片、边缘缺口、展开对称复制）由原生 SVG 几何算法实现
- 全部音效由 Web Audio API 实时合成，零外部音频文件
- 轨迹辅助系统按房间难度自动分级（平滑 + 简化 + 吸附）
- 倒计时 ≤10 秒触发多层加速：视觉脉冲 + 时间间隔递减 + 音效频率升高
- 5 位 Bot 各有独立人设、猜题策略和萌系口头禅，模拟真实多人竞猜氛围

### 一句话版

剪纸版「你画我猜」—— 玩家在折叠红纸上剪局部，系统自动展开成对称图案，Bot 来猜你剪了什么。

## 我的工作（个人贡献说明）

1. **玩法概念与设计**：独立完成游戏核心机制设计（折叠-剪裁-展开-竞猜闭环）、房间难度体系、Bot 猜题策略、计分规则。
2. **前端全栈开发**：独立完成 React + TypeScript + Vite 全栈开发，包括剪纸编辑器（SVG 指针交互 + 几何算法）、Bot 竞猜系统、音效合成、倒计时加速效果、全游戏 UI。
3. **剪纸物理引擎**：从零实现折叠区域 clamp、闭合路径检测、边缘掉片判断、展开对称复制算法、轨迹平滑（移动平均 + RDP 简化）、吸附闭合辅助。
4. **视觉与世界观**：萌系治愈风视觉体系、气泡浮游动画、萌系 Bot 人设卡片、全游戏 40+ 处文案优化。
5. **提交材料**：独立撰写参赛设计方案、MVP 开发任务拆解、作品集提交说明、README 等技术文档。

## 评审看点提示

如果你只有 3 分钟了解这个项目，请重点看：

1. **玩法创新**：剪纸不是皮肤，是机制。打开 `02-drawing.png` 感受「折叠纸面 + 展开预览」的双栏结构。
2. **物理剪纸**：看看 `src/game/paper-cutting.ts`，闭合掉片、边缘缺口、展开对称复制的几何算法。
3. **Bot 系统**：5 位萌系 Bot 各有独立人设和猜题策略（`src/data/constants.ts`）。
4. **倒计时加速**：≤10 秒的时间感知压缩 + 视觉脉冲 + 音效升频，让等待本身成为体验。
5. **工程完整度**：React 19 + TypeScript + Vite 7，16 个源文件，模块职责清晰，零 lint 错误。
